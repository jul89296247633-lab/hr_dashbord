# HR Control Tower — Платформа прозрачности и аналитики HR-отдела

> Внутренний инструмент для HR-отдела (5 менеджеров + руководитель): автоматически собирает данные воронки из HH.ru API, принимает CSV-выгрузки из раздела «Аналитика подбора» HH (звонки, индекс вежливости), синхронизирует три листа Google Sheets — показывает эффективность каждого менеджера, ИВ и подразделений в реальном времени.

---

## 1. Проблема

### Текущая ситуация (AS-IS)

Руководитель HR-отдела собирает данные вручную: воронка и отклики — из HH.ru, звонки и индекс вежливости менеджеров — в интерфейсе HH (раздел «Аналитика подбора»), данные о закрытых вакансиях и бонусах — из Google Sheets. Нет системы, которая объединяет всё это в единую картину.

### Боль

- Руководитель тратит 3–5 часов в неделю на сборку отчётов из HH и Sheets
- Звонки есть в отчёте HH «Аналитика подбора → Звонки», но их нельзя сравнить с KPI и планом без ручной работы
- Индекс вежливости менеджеров и компании виден в HH — но отдельно от воронки и плана
- Воронка по вакансии — «чёрный ящик»: 7 этапов, включая стажировку, не отслеживаются
- Бонусы начисляются в Sheets — нет прозрачности для менеджеров
- Срок закрытия вакансии не считается автоматически
- Plan (15 звонков, 5 собеседований, 15 выводов/мес) не отслеживается в реальном времени

### Цена проблемы

Отдел теряет ~40 часов/мес на ручные операции. Руководство не видит в одном месте: кто звонит, кто отвечает кандидатам, чей ИВ падает. Задержка закрытия вакансий — 1–2 недели из-за неуправляемой воронки.

---

## 2. Целевая аудитория

### Основная (ядро)

- **Кто:** Руководитель HR + 5 HR-менеджеров
- **Инструменты:** HH.ru (с аналитикой подбора и встроенными звонками) + Google Sheets
- **Ценность:** экономия 40+ часов/мес + прозрачность KPI, ИВ и бонусов в одном месте

### Вторичная

- **Кто:** Топ-менеджмент — читает дашборд укомплектованности и ИВ компании как бизнес-метрики

### Антиаудитория

- Компании без HH.ru или без раздела «Аналитика подбора»
- Компании с 1 рекрутёром — нет смысла в командной аналитике

---

## 3. Решение

### Формула ценности

Руководитель открывает дашборд → видит в одном месте: ИВ компании, ИВ каждого менеджера, воронку по вакансиям (7 этапов), KPI vs план, бонусы — всё без ручных отчётов.

### Ключевые функции (0 для MVP)

| # | Функция | Пользователь делает | Система делает | Результат |
|---|---------|---------------------|----------------|-----------|
| 1 | Личный кабинет менеджера | Вносит собеседования и офферы за день | Отображает звонки из Манго (cron) + HH (CSV). Итого = сумма | 5 мин/день вместо 60 |
| 2 | Авто-сбор воронки из HH API | Ничего | По каждой вакансии: отклики, открытые контакты, приглашения (cron каждые 2ч) | Этапы 1–3 воронки без ручного ввода |
| 3 | Авто-сбор звонков Манго (cron) | Ничего | cron 20:00: Манго API `vpbx/stats/request` по добавочному номеру менеджера | Звонки Манго автоматически |
| 4 | Загрузка CSV «Звонки» из HH | Руководитель скачивает CSV из HH → /sync | Парсит, привязывает к менеджерам. Итого = mango_calls + hh_calls | Звонки HH для менеджеров без Манго |
| 5 | Загрузка CSV «Индекс вежливости менеджеров» | То же | Парсит ИВ, отклики, просмотренные, ответы, среднее время ответа по каждому менеджеру | ИВ по менеджерам в дашборде |
| 6 | Загрузка CSV «Индекс вежливости компании» | То же | Сохраняет сводный ИВ компании | ИВ компании в дашборде |
| 7 | Синхронизация Google Sheets (3 листа) | Руководитель нажимает «Синхронизировать» | «Вакансии» (статус + даты), «HR менеджеры» (список команды), «Бонусы_HR» (начисления) | Закрытые вакансии, команда и бонусы актуальны |
| 8 | Воронка подбора — 7 этапов | Открывает страницу вакансии | Отклик → Контакт → Приглашение → Звонок → Собеседование → **Стажировка** → Трудоустройство | Видно где теряются кандидаты |
| 9 | Срок закрытия вакансии | Ничего | Вычисляет `closed_at − opened_at` при синхронизации Sheets | Средний срок по подразделению |
| 10 | Три дашборда (отдел / эффективность / подразделения) | Открывает нужную вкладку | Сводный: ИВ компании + KPI; Эффективность: ИВ + звонки + план; Подразделения: воронка + сроки | Всё в 2 клика |
| 11 | Бонусы HR | Открывает /bonuses | Показывает начисления из Sheets, привязанные к закрытым вакансиям | Прозрачность бонусов |
| 12 | AI-аналитика: аномалии | Руководитель открывает /ai | Еженедельно анализирует KPI каждого менеджера, выявляет отклонения (падение звонков, ИВ, простои) с severity high/medium/low | Руководитель видит проблемы до конца месяца |
| 13 | AI-аналитика: прогнозы | Ничего | Математически прогнозирует выполнение плана по каждому менеджеру, AI добавляет текстовую интерпретацию | «Иванова закроет месяц на 94%» |
| 14 | AI-аналитика: рекомендации по воронке | Ничего | Находит вакансии с узкими местами (конверсия контакт→звонок <40%), генерирует конкретные рекомендации | Руководитель знает что исправить |
| 15 | AI еженедельный отчёт | Ничего — cron пятница 20:30 | Собирает все данные за неделю, генерирует структурированный отчёт (500–700 слов, Markdown): итоги, KPI, лучший/худший менеджер, приоритеты | Готовый отчёт без ручного труда |

### Что НЕ входит в MVP

- Автоматическая загрузка CSV из HH (только ручная — скачать и загрузить)
- Определение какой именно кандидат был прозвонён (считаем общее число попыток)
- Мобильное приложение
- AI-анализ и рекомендации
- Публичный доступ и мультитенантность
- Привязка звонка к конкретной вакансии (агрегируется по менеджеру)

## 4. Ограничения

### Технические

- **Интеграции:**
  - HH.ru API v3 — автоматически (cron 2ч): вакансии, отклики, контакты, приглашения по вакансиям
  - Манго ВATС API — автоматически (cron 20:00): `vpbx/stats/request` по `from.extension` менеджера
  - HH.ru CSV-выгрузки — вручную через /sync: звонки HH, ИВ менеджеров, ИВ компании (windows-1251)
    - **Фильтр:** в анализ берутся только менеджеры из листа «HR менеджеры» Google Sheets; остальные — игнорируются
    - **Fuzzy-match имён:** если имя в HH («Иванова М.») не совпадает точно с именем в Sheets («Иванова Мария») — система автоматически сопоставляет через алгоритм Левенштейна (порог 70%). Результаты fuzzy-матчей показываются руководителю для ручной проверки
  - Итого звонков: `mango_calls + hh_calls` (каждый менеджер использует один или оба источника)
  - Anthropic Messages API (claude-sonnet-4-5) — AI-анализ: аномалии, прогнозы, рекомендации, еженедельный отчёт
  - Google Sheets API v4 (service account) — три листа: «Вакансии», «HR менеджеры», «Бонусы_HR»
- **Авторизация:** 4 роли: менеджер / руководитель / топ-менеджмент / администратор
- **Стек:** Next.js 15, Supabase, Vercel (фронт), Beget VPS (cron HH API)

### Бизнесовые

- **Юрисдикция:** Россия | **Платежи:** нет | **152-ФЗ:** доступ только для сотрудников компании

## 5. Критерии успеха

### MVP считается успешным, если:

1. Руководитель видит ИВ компании и ИВ каждого менеджера в одном дашборде без ручной сборки
2. Воронка по каждой вакансии (7 этапов) актуальна без ручного ввода данных из HH
3. После загрузки CSV из HH: звонки и ИВ привязаны к конкретным менеджерам
4. Менеджер вводит только собеседования — всё остальное подтягивается автоматически или через CSV
5. Срок закрытия вакансий считается автоматически, аналитика по подразделениям доступна

6. AI еженедельный отчёт генерируется автоматически каждую пятницу и не требует ручного составления
7. Руководитель получает уведомление об аномалиях в тот же день, когда они возникают
8. Admin видит все ошибки системы (error_logs) и историю изменений (audit_logs) в одном месте

### Метрики:

- **Активация:** Менеджер внёс данные 3 дня подряд
- **Retention:** Все менеджеры используют кабинет ежедневно через 2 недели
- **CSV:** Руководитель загружает CSV из HH минимум 2 раза в неделю (это единственная ручная операция)
- **ИВ:** Несопоставленных менеджеров в CSV ≤ 0 (все имена привязаны к профилям)
- **Бонусы:** ≤ 5% бонусов без привязки к вакансии

## 7. Дорожная карта (после MVP)

### Фаза 2 — Telegram-интеграция

**Telegram-бот для HR-менеджеров:**
- Авторизация через deeplink (`/start?token=xxx` — ссылка из системы, без пароля)
- Ввод дневных активностей: собеседования, офферы, заметки — прямо в чат
- Напоминание в 19:00 в рабочие дни «Не забудь внести данные за сегодня»
- AI-уведомления руководителю: аномалии и еженедельный отчёт в Telegram

**Telegram Mini App:**
- Личный кабинет менеджера (KPI, форма ввода) — в мини-апп внутри Telegram
- Дашборд руководителя (ИВ компании, KPI отдела, топ/аутсайдер недели)
- Открывается кнопкой в боте, авторизация через Telegram WebApp API

*Архитектура фазы 2 проектируется отдельным блоком после запуска MVP*

### Фаза 3 — SaaS

- Мультитенантность (один инстанс — несколько компаний)
- Биллинг (ЮKassa), тарифные планы
- Self-service онбординг: компания регистрируется сама, подключает HH и Sheets без IT
- Публичный лендинг и маркетинг
