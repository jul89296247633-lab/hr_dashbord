# Досрочный сход кандидата в презентации

## Цель

Дать HR возможность убрать из активного списка `/present` карточку потенциального кандидата, который сошёл с дистанции до подтверждения в Borboza.

## Объём

- В общей карточке кандидата показывать кнопку `Сошла с дистанции досрочно` только при пустом `podbor_people.external_id`.
- Перед действием запрашивать подтверждение.
- По действию устанавливать `podbor_people.archived = true`.
- После действия возвращать пользователя в общий список `/present` с сообщением об успехе.
- На сервере запрещать действие, если к моменту запроса у карточки появился `external_id`.

## Не входит

- Удаление строки `podbor_people` или файла из Storage.
- Удаление кандидата из уже созданных подборок.
- Изменение данных Borboza, KPI или сопоставлений.
- Восстановление архивной карточки через UI.

## Бизнес-правила

1. Заполненный `external_id` означает, что карточка сопоставлена с подтверждённым сотрудником Borboza.
2. Подтверждённую карточку нельзя архивировать этим действием, даже если отправить POST вручную.
3. Архивирование скрывает карточку из активного списка за счёт существующего фильтра `archived = false`.
4. Фото, описание, дата стажировки и история подборок сохраняются.

## Состояния UI

- `external_id` пуст: видны чекбокс `выбрать` и кнопка досрочного схода.
- `external_id` заполнен: виден только чекбокс `выбрать`.
- Успех: карточка исчезает из активного списка, сверху показано подтверждение.
- Ошибка или карточка уже сопоставлена: карточка остаётся, сверху показана причина.

## Проверки

- API `people` возвращает `external_id` внутреннему экрану.
- `archive_person` отклоняет пустой/несуществующий `person_id`.
- `archive_person` отклоняет карточку с `external_id`.
- Для неподтверждённой карточки изменяется только `archived`.
- HTML не содержит вложенных форм.
- `/present`, `/rookies` и `/api/photo` продолжают работать в production.

## Критерии приёмки

- Кнопка доступна только у кандидатов без подтверждения Borboza.
- После подтверждения кандидат исчезает из общего списка `/present`.
- Строка кандидата и фотография не удаляются.
- Ранее созданные подборки остаются неизменными.
- Сервер не позволяет архивировать подтверждённого кандидата.
