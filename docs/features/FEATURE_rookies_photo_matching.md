# Фото новичков из карточек презентации

## Цель

На `/rookies` показывать фотографию из блока презентации, когда строка Borboza и карточка HR описывают одного человека, но ещё хранятся отдельными записями.

## Объём

- Для новичка без `photo_path` искать совпадение среди активных `podbor_people` с фотографией.
- Сопоставлять ФИО без учёта регистра, пунктуации, `ё/е` и порядка слов.
- Допускать отсутствие одного отчества, если совпадают остальные части имени.
- Если город заполнен с обеих сторон, требовать его точного нормализованного совпадения.
- Использовать результат только при единственном совпадении.
- Подставлять существующий `photo_path` и отсутствующую дату стажировки в отображаемую карточку.

## Не входит

- Копирование файла в Storage.
- Автоматическое объединение или удаление строк `podbor_people`.
- Автоматическая запись `external_id` по одному ФИО.
- Сопоставление при нескольких подходящих карточках.

## Бизнес-правила

1. Источник фотографии — активная карточка презентации с заполненным `photo_path`.
2. Архивные карточки, включая досрочно сошедших кандидатов, не участвуют.
3. Разные заполненные города запрещают автоматическое совпадение.
4. Два и более подходящих человека считаются неоднозначностью: фото не показывается до ручного связывания.
5. В базе и Storage ничего не переносится; оба экрана используют один существующий файл.

## Критерии приёмки

- `Имя Фамилия` совпадает с `Фамилия Имя` в том же городе.
- Карточка с дополнительным отчеством может совпасть с теми же именем и фамилией.
- Одинаковое имя в разных заполненных городах не совпадает.
- При двух допустимых карточках фото не выбирается автоматически.
- После деплоя `/rookies` продолжает показывать KPI и использует `/api/photo` для найденных фотографий.
